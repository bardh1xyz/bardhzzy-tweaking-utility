# bardhzzy-tweaking-utility 

A custom batch script designed to optimize system performance, minimize background processes, and debloat Windows.

## Features
* **OS Debloating:** Removes telemetry and unnecessary pre-installed services.
* **Performance Optimizations:** Tweaks system responsiveness and resource management.
* **Streamlined Workflow:** Lightweight design built to run entirely from the command line.

## How to Use
1. Right-click the `.bat` file.
2. Select **Run as Administrator**.
3. Create a restore point (option 11) and a registry backup (option 16)
4. Run all the other options
